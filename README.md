# kr2-bootstrap-shop — Винтаж-лавка на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Интернет-магазин винтажных вещей «Винтаж-лавка»: плёночные камеры, инструменты, канцелярия и предметы интерьера. Предметная область та же, что в КР №1, но сайт свёрстан заново на Bootstrap: сетка, компоненты и формы взяты из фреймворка, а `css/custom.css` задаёт только фирменный стиль.

В проекте 5 страниц, 8 товаров, светлая и тёмная тема, избранное, фильтры каталога и оформление заказа с расчётом суммы.

## Используемый фреймворк

Bootstrap 5.3.8 (CSS и JS Bundle с Popper).

## Способ подключения Bootstrap

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка (compiled-версия) размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Порядок подключения на каждой странице:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css" />
<link rel="stylesheet" href="css/custom.css" />

<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/products.js"></script>
<script src="js/main.js"></script>
```

Сначала подключается Bootstrap, затем свои стили, чтобы их можно было переопределять. JS Bundle подключается перед своими скриптами: он нужен для мобильного меню, модальных окон, offcanvas, accordion, carousel, tabs и toast. Из внешних ресурсов подключены только шрифты Google Fonts (Inter и Playfair Display); без интернета сайт работает на системных шрифтах.

## Bootstrap-сетка

- `container` — во всех секциях;
- `row` и колонки `col-12`, `col-6`, `col-sm-6`, `col-md-4`, `col-md-6`, `col-md-8`, `col-lg-3` … `col-lg-9`, `col-xl-4`;
- отступы между колонками — `g-3`, `g-4`, `g-lg-4`, `g-lg-5`.

Карточки перестраиваются: 1 колонка на телефоне → 2 на планшете → 3–4 на компьютере. Горизонтальной прокрутки нет ни на одной ширине (проверено на 375, 768 и 1280 px).

## Реализованные Bootstrap-компоненты

Обязательные:

- `navbar` — на всех страницах, с мобильным меню (`navbar-toggler` + `collapse`);
- `card` — карточки товаров, преимуществ, контактов, итог заказа;
- `btn` — `btn-primary`, `btn-outline-primary`, `btn-light`, `btn-link`, размер `btn-lg`, нажатое состояние `.active`;
- `badge` — метки «Хит», «Новинка», «−20%», счётчики избранного и фильтров;
- `alert` — промокод на главной (закрывается), ошибка формы заказа, «ничего не найдено» в каталоге, «товар не найден», подтверждение заказа;
- `modal` — быстрый заказ (главная, каталог) и «Заказ принят» (заказ);
- `form-control`, `form-select`, `input-group`, `form-check` — во всех формах;
- дополнительный компонент — `accordion`.

Дополнительные:

- `carousel` — галерея фото на странице товара;
- `nav-tabs` (tabs) — вкладки на странице товара;
- `toast` — уведомления об избранном, подписке и отправке форм;
- `offcanvas` — панель избранного и фильтры каталога на телефоне;
- `pagination` — страницы каталога;
- `breadcrumb`, `list-group`, `collapse`, `table` (`table-striped`, `table-bordered`, `table-active`), `blockquote`, `ratio`, `form-switch`, валидация форм (`was-validated`, `invalid-feedback`).

## Что находится в custom.css

Раскладка, отступы, пропорции фото (`ratio`, `object-fit-cover`) и типографика сделаны утилитами Bootstrap. Тёмные подвал и полоса подписки — встроенная тёмная тема (`data-bs-theme="dark"`). В `custom.css` осталось только то, чего в Bootstrap нет:

- фирменная палитра через переменные Bootstrap: `--bs-primary`, `--bs-body-bg`, `--bs-border-color` и другие, отдельно для светлой и тёмной темы;
- перекраска `btn-primary`, `btn-outline-primary`, `pagination`, `accordion` и фокуса полей через переменные компонентов (их цвета в Bootstrap скомпилированы заранее);
- шрифты: Playfair Display для заголовков, Inter для текста;
- свои бейджи `badge-hit`, `badge-new`, `badge-sale`;
- круглые кнопки-иконки, сердечко избранного, смещение липких блоков под шапку;
- фото в hero в виде полароидных снимков, затемнение плиток категорий, подъём карточек при наведении.

Карточка товара описана один раз — функцией `renderCard` в `main.js`. Её используют главная, каталог и страница товара. Списки товаров в формах тоже строятся из `products.js`, поэтому цены и названия меняются в одном месте.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** — файлы в `vendor/bootstrap/`, сайт работает без CDN.
2. **Дополнительная страница `contacts.html`** с формой обратной связи и FAQ о продаже вещей.
3. **Каталог с фильтрами**: поиск по названию, категории (чекбоксы), диапазон цен, переключатель «только со скидкой», сортировка, счётчик найденных товаров, сброс фильтров, разбивка на страницы. Переход с плитки категории на главной сразу включает нужный фильтр (`catalog.html?cat=cameras`).
4. **Одна страница товара для всех 8 товаров**: `product.html?id=…` берёт данные из `js/products.js`. Без параметра показывается камера. Для неверного id выводится сообщение «Товар не найден».
5. **Сценарий заказа**: кнопка «Оформить заказ» на странице товара передаёт товар и количество в форму (`order.html?product=…&qty=…`). Форма считает итог в реальном времени: количество, стоимость доставки (курьер бесплатно от 5 000 ₽), промокод `VINTAGE10` на 10%. Поле адреса появляется только для курьера и почты. После отправки открывается окно с номером заказа.
6. **Быстрый заказ из карточки**: окно открывается с уже выбранным товаром.
7. **Проверка форм в стиле Bootstrap**: подсказки под полями, проверка телефона (ровно 10 цифр), фокус на первое ошибочное поле. Атрибут `novalidate` ставит скрипт, поэтому без JavaScript работает обычная проверка браузера.
8. **Избранное**: сердечко на карточках и странице товара, счётчик в шапке, список в выезжающей панели. Сохраняется в `localStorage` между страницами.
9. **Светлая и тёмная тема** на встроенной в Bootstrap 5.3 поддержке `data-bs-theme`. Выбор запоминается.
10. **Таблица сравнения** с похожими товарами той же категории и блок «Вам может понравиться».
11. **Доступность**: ссылка «Перейти к содержимому», `aria-label` у кнопок-иконок, `aria-current` в меню и пагинации, подписи у всех полей, `alt` у изображений.

## Как проверить проект

1. Откройте `index.html` в браузере или перейдите по ссылке GitHub Pages.
2. **Сетка**: в DevTools включите режим устройства и проверьте ширины 375, 768 и 1280 px. Карточки перестраиваются, горизонтальной прокрутки нет.
3. **Меню**: на узком экране нажмите «бургер» — меню раскрывается.
4. **Каталог**: отметьте категорию, введите цену «до 2000», включите «только со скидкой», смените сортировку, переключите страницу 2. При пустом результате появится предупреждение.
5. **Быстрый заказ**: на карточке нажмите «Быстрый заказ». Отправьте пустую форму — увидите подсказки. Заполните — окно закроется, появится уведомление.
6. **Товар**: «Подробнее» → переключите фото и вкладки, нажмите «В избранное» (счётчик в шапке увеличится), затем «Оформить заказ».
7. **Заказ**: товар и количество уже выбраны. Выберите курьера — появится поле адреса. Введите промокод `VINTAGE10` — итог уменьшится на 10%. Отправьте форму — откроется окно «Заказ принят».
8. **Тема**: нажмите значок луны в шапке. Тема сохранится при переходе между страницами.
